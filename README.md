# AIVLE 스쿨 7차 미니프로젝트

### 목표 : AIVLE 스쿨 6기 모집 관련 챗봇 사이트 제작
RAG 모델을 활용하여 현재 진행 중인 6기 모집에 관해, 궁금한 점을 질문하면 답변해주는 챗봇을 만들어보자.

- 챗GPT 프롬프트 튜닝
- LangChain을 활용한 RAG 모델 만들기
- 웹크롤링을 통한 데이터 수집
- Django를 활용한 웹 사이트 제작

### 개인 역할

- RAG 모델 구축
  - ChatGPT 프롬프트 튜닝 진행
  - LangChain을 활용한 메모리 직렬화
- RAG 참조를 위한 웹크롤링
  - AIVLE 스쿨 FAQ 페이지 내용
  - 동기수 교육생들의 AIVLE 스쿨 리뷰 블로그 내용
  - chroma DB 구축 및 RAG 파이프라인에서 활용
- UI/UX 작업
